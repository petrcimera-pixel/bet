Zápasy

Zápasy z celého světa s predikcí výsledku a kurzy. Klikni na řádek pro detail, na kurz pro vsazení — 💎 značí nalezenou value. Pod kurzem vidíš pravděpodobnost podle modelu.

Tikety dne

Moje tikety = tvoje vsazené akumulátory. Tikety dne = hotové návrhy modelu (Jistota / Value / Odvážný), které si můžeš vsadit.

🧾 Moje tikety — tvoje vsazené akumulátory

✨ Tikety dne — návrhy modelu, ještě nevsazené

Alerty

Upozornění na výrazné příležitosti: silné value (1X2 i rohy), velký rozkol kurzů mezi sázkovkami a zápasy s vysokou jistotou.

Kalibrace modelu

Jak přesný je model? Přehraje predikce na už odehraných zápasech a porovná je s realitou. Vyšší přesnost a nižší Brier = lepší.

Zpětný test modelu na odehraných zápasech – jak přesné jsou predikce.

Nastavení

Pokročilé nastavení — parametry predikčního modelu, vzhled aplikace, správa dat a sázkové/API volby.

🧠 Parametry modelu

Změna se projeví okamžitě u nově načtených predikcí (keš se vyprázdní). Pro většinu uživatelů jsou výchozí hodnoty optimální.

Korekce nezávislosti nízkých skóre (0-0, 1-0…). Standardní hodnota z literatury je −0.13.

🎨 Vzhled

Vzhled se ukládá a projeví okamžitě, bez nutnosti obnovit stránku.

💵 Sázkové a API

Frakční Kelly = jaký podíl doporučené sázky reálně vsadíš. ¼ Kelly (0.25) je bezpečný kompromis mezi růstem a rizikem.

Volitelné: vlož bezplatný klíč z the-odds-api.com a u zápasů se použijí skutečné kurzy sázkovek místo modelovaných. Bez klíče jede model.
